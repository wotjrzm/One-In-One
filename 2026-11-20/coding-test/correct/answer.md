# 팰린드롬 판별

결과: 정답

## 제출한 코드

```python
def solution(s):
  return s == s[::-1]
```

## 해설

문자열을 뒤집은 결과가 원래 문자열과 같은지 비교하면 됩니다(s == s[::-1]). 또는 양 끝에서 한 글자씩 안쪽으로 이동하며 두 문자가 모두 같은지 확인해도 됩니다. 빈 문자열과 한 글자 문자열은 항상 팰린드롬이고, 대소문자를 구분하므로 "Aa"는 팰린드롬이 아닙니다.
