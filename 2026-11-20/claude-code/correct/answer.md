## 해설

MCP는 AI 도구를 외부 도구와 데이터 소스에 연결하는 오픈 표준으로, MCP 서버를 연결하면 Claude가 이슈 트래커나 데이터베이스 등을 직접 읽고 다룰 수 있습니다. 프로젝트 범위(project scope)로 추가한 서버는 프로젝트 루트의 .mcp.json에 저장되어 버전 관리로 팀과 공유됩니다. CLAUDE.md는 지침 파일일 뿐 서버 연결 설정을 담는 곳이 아닙니다.
